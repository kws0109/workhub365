Microsoft 365 연동

회사 계정 그대로,
그룹웨어를 시작합니다

Microsoft 365를 쓰고 있다면 새로 계정을 만들 필요가 없습니다. 직원은 쓰던 회사 계정으로 로그인해 휴가·근태·전자결재를 처리하고, 관리자는 입·퇴사 처리와 라이선스 정리를 자동화합니다.

오픈소스(MIT) · 자체 테넌트에 직접 설치해 사용합니다

이런 상황을 위해 만들었습니다

결재는 여전히 메신저와 메일로

Microsoft 365에는 휴가 신청이나 전자결재 같은 국내 업무 흐름이 들어 있지 않습니다. 그래서 승인 기록이 대화방에 흩어집니다.

안 쓰는 라이선스가 계속 결제된다

누가 몇 달째 로그인하지 않았는지, 그래서 매달 얼마가 새는지 한 화면에서 보기 어렵습니다.

퇴사 처리를 매번 손으로

계정 차단, 세션 종료, 라이선스 회수, 그룹 제거를 관리 센터를 오가며 하나씩 처리합니다. 빠뜨려도 알기 어렵습니다.

기능

직원이 매일 쓰는 기능과 관리자가 가끔 쓰는 기능을 한 곳에 담았습니다.

직원

휴가 · 근태

캘린더에서 날짜를 눌러 신청하면 결재선을 따라 승인되고 잔여 연차가 자동으로 차감됩니다.

  • 공휴일을 자동으로 받아와 주말·휴일 신청은 미리 막습니다
  • 출퇴근 기록을 주 단위로 집계하고 52시간에 근접하면 알려줍니다
  • 팀 캘린더에서 부서원 휴가 현황을 한눈에 봅니다
직원

전자결재

경비·데이터 반출·휴직·구매 네 가지 서식을 제공하고, 부서장에서 관리자로 이어지는 결재선을 자동으로 구성합니다.

  • 결재선은 필요하면 직접 수정할 수 있습니다
  • 제출 시점의 문서를 그대로 보존해 나중에 서식이 바뀌어도 기록이 유지됩니다
관리자

라이선스 관리

보유·할당·미할당 좌석을 보여주고, 쓰지 않는 라이선스가 매달 얼마인지 원화로 환산합니다.

  • 비활성 기준을 30·60·90일로 바꿔가며 볼 수 있습니다
  • 회수 대상을 근거와 함께 추천합니다
  • 계약 단가를 입력하면 금액에 바로 반영됩니다
관리자

입·퇴사 처리

계정 생성부터 라이선스 배정, 그룹 배정까지 한 번에 진행하고, 퇴사는 차단·세션 종료·회수·그룹 제거를 순서대로 실행합니다.

  • 진행 상황이 단계별로 표시되고, 중간에 실패하면 그 지점부터 다시 시도합니다
  • 임시 비밀번호는 화면에 한 번만 표시하고 저장하지 않습니다
인사

근태 · 휴가 정정

인사 담당자가 직원의 잘못된 기록을 직접 고칩니다. 퇴근 체크를 잊은 기록을 닫거나, 빠진 근무일을 대신 입력할 수 있습니다.

  • 정정에는 사유를 반드시 남기고 변경 전후가 기록됩니다
  • 승인된 휴가를 줄이면 연차가 자동으로 되돌아옵니다
  • 본인 기록은 관리자라도 고칠 수 없습니다
AI

AI 어시스턴트

"이번 달 안 쓰는 라이선스가 얼마야?" 처럼 말로 물어보면 확인해서 답하고, 필요한 처리까지 대신합니다.

  • 계정 차단이나 라이선스 회수처럼 되돌리기 어려운 작업은 담당자가 승인해야만 실행됩니다
  • 승인 화면에 대상이 누구인지 이름으로 표시됩니다
  • 직원은 자기 연차·근무시간·결재 상태만 물어볼 수 있습니다

화면

실제 Microsoft 365 테넌트에 연결한 상태의 화면입니다.

Microsoft 365를 대체하지 않습니다

메일은 Outlook에서, 파일은 OneDrive에서 쓰는 게 낫습니다. WorkHub365는 그 위에 없는 것만 더하고, 나머지는 연결합니다.

가져오는 것

  • 회사 계정 로그인 — 별도 아이디·비밀번호가 없습니다
  • 메일함, 일정, 문서, 조직도, 자리 비움 상태
  • 라이선스 보유 현황과 마지막 로그인 기록

넘기는 것

  • 메일 답장·전달은 Outlook으로 바로 이동합니다
  • 파일 업로드와 편집은 OneDrive·Office에서
  • 필요한 권한만 요청하기 위해, 쓰기 작업은 대부분 원래 앱으로 넘깁니다
