# 목업 기능 맵 — 화면별 구성과 신규 항목 B1~B17

> 이 문서는 2026-08-09 세션에서 빈 파일로 커밋돼 내용이 유실됐고, 목업 원본(`workhub365-mockup.html`)과 스펙(requirements M8·R5.1, design.md M8)에서 재구성했다. **B 번호는 handoff.md에 남은 참조(B11=감사 필터 탭+검색, B12=결재 마스터-디테일, B13=라이선스 AI 일괄 회수, B14=온보딩 최근 실행 이력, B15=전직원 개방)를 고정점으로 삼아 재구성**했으며, 나머지 번호는 목업 발견 순서(협업 화면 → 홈 위젯 → 공통 → 기존 화면 개선)로 부여했다.

목업 데모 설정: 페르소나 김서연(개발팀), 기준일 2026-08-13(목). props로 `role`(admin/employee — 관리 섹션·관리자 위젯 게이트)과 `chips`(출처 칩 표시)를 토글한다. 모든 데이터는 하드코딩 가짜 데이터 — 각 화면 절의 "실데이터 대체"가 치환 계획이다.

## 셸 (사이드바)

- **레이아웃**: 좌측 고정 224px + 우측 콘텐츠(overflow-y, 패딩 32). 최소 폭 1280 가정, 상단 헤더 없음
- **구성**: 로고 → nav 4섹션(내 업무: 홈/메일/일정/전자결재/근태·휴가 · 협업: 게시판/문서함/메신저/회의실/조직도 · AI: 어시스턴트 · 관리(admin만): 라이선스/온보딩·오프보딩/감사 로그) → M365 앱 바로가기(Outlook/Teams/OneDrive/Planner, 새 탭+외부 아이콘) → 사용자 푸터(이름·부서·역할·로그아웃)
- **배지**: 메일 12(안읽음, neutral), 전자결재 2(내 차례, notice 톤), 메신저 3
- **실데이터 대체**: 메일 배지=위임 `Mail.Read` inbox `unreadItemCount` 스냅샷(B10, 구현됨), 결재 배지=`countMyTurnProposals`(구현됨). 메신저 항목은 **제외** — Teams 딥링크가 M365 섹션에서 대체(R8.7). 관리 섹션은 role 게이트 현행 유지

  - 4열 위젯: 안읽은 메일 12통(Outlook 칩, 딥링크) · 오늘 일정 3건(시각+제목 리스트) · Teams 멘션 3건(**제외 대상**) · 최근 문서 3건(파일타입 아이콘+이름)

## 8. 메신저 — 제외 (R8.7)

목업 구성(기록용): 대화 목록 300px(검색, 아바타+프레즌스, 미리보기, 안읽음 카운트 `#dc2626`) + 채팅 영역(채널 헤더, 날짜 구분선, 버블 — 내 것 inverse/멘션 amber 강조/파일 칩, 입력 바). **전체 화면을 구현하지 않는다** — Teams 채팅 본문은 protected API(Microsoft 승인 필요, CLAUDE.md 알려진 제약)이고, 자체 DB 채팅은 "M365 위에 얹는다" 정체성에 반한다(design.md). 사이드바·홈에서 Teams **딥링크로 대체**하고, 홈 "Teams 멘션" 위젯과 조직도 채팅 아이콘 연출도 같은 이유로 Teams 딥링크 처리
