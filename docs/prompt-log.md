# 프롬프트 로그

AI 페어 프로그래밍으로 구현한 작업마다 **[근거 스펙 + 실행 프롬프트]**를 기록한다 (N6 투명성).
목적: 대화 히스토리가 없는 새 세션(또는 제3자)이 이 로그만 보고 ① 무엇을 근거로 ② 어떤 지시로 구현됐는지 재현할 수 있게 한다.

- 형식: 항목당 [날짜 / 작업 / 근거 스펙 / 실행 프롬프트 / 결과 커밋]. 프롬프트는 실제 사용한 문구를 그대로 인용한다
- 2026-08-09 이전 항목은 세션 기록(transcript)에서 **소급 발췌·복원**한 것이다. 원문 인용이 원칙이며, "(요약)" 표기가 붙은 것만 공개 문서에 맞게 맥락을 요약·일반화했다
- 짧은 지시("Phase N 진행해줘")로 큰 작업이 진행된 것은 스펙 주도 개발의 결과다 — 상세 요구는 [specs/](specs/)가 대신하고, 프롬프트는 트리거 역할만 한다
